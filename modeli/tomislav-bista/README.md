| | |
|---|---|
| Datoteka | `tomislav-bista.glb` (1.4 MB, glTF 2.0 binary) |
| Geometrija | ~80k trokuta (decimirano s 300k), bez tekstura i materijala |

| Materijal | zadaje viewer: bronca / brački kamen / patina (v. `docs/VIEWER-SPEC.md`) |

## ⚠️ Atribucija — NEPOTVRĐENO

Autorstvo skulpture s koje potječe scan **nije potvrđeno**. Tvrdnja
„autori Ivo Kerdić i Rudolf Betzler" NE prolazi provjeru (Kerdić je radio
medalje/plakete Tomislava 1925., ne bistu; za Betzlera nema veze s Tomislavom).
Dokumentirana povijesna bista kralja Tomislava: **Stari grad Ozalj (1933.),
autor Robert Frangeš Mihanović** (Ozalj je DBHZ lokalitet). Do potvrde s
Družbom model tretirati kao **ilustrativnu 3D digitalizaciju za demo**, bez
javnog pripisivanja autorstva.

## Kontekst

DBHZ je glavni inicijator obilježavanja 1100. obljetnice Hrvatskoga Kraljevstva.
U DBHZ novčanik prototipu model služi kao crowdfunding vizualizacija (odljev u
bronci/kamenu i postavljanje po gradovima) — ekran `bista`,
[dbhz-prototip.domovina.ai](https://dbhz-prototip.domovina.ai/?screen=bista).

Javni katalog: [dbhz-3d-modeli.domovina.ai/?id=tomislav-bista](https://dbhz-3d-modeli.domovina.ai/?id=tomislav-bista)
(s napomenom o nepotvrđenoj atribuciji).
